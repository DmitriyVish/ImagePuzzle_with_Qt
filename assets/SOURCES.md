# Ресурсы оформления

Иконка приложения: Microsoft Fluent Emoji, «Puzzle piece», вариант Flat.
- Исходный SVG: https://github.com/microsoft/fluentui-emoji/blob/main/assets/Puzzle%20piece/Flat/puzzle_piece_flat.svg
- Лицензия MIT: https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE
- Локальная копия лицензии: icons/Fluent-Emoji-MIT.txt (Copyright Microsoft Corporation).
- icons/imagepuzzle.svg — исходный рисунок без изменений; icons/imagepuzzle.ico — тот же рисунок,
  преобразованный в размеры 16, 20, 24, 32, 40, 48, 64, 128 и 256 пикселей с прозрачностью.
  Растеризация выполнена Qt SVG; упаковка ICO — Pillow. Новая runtime-зависимость от Qt SVG не требуется.

Фотографии: официальный сайт музея «Малые Корелы». Включены для музейного приложения по запросу пользователя. Индивидуальные авторские подписи на главной странице не указаны.
